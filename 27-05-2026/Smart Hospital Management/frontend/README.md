# Hospital Management Frontend

This folder contains an Angular frontend scaffold for the existing backend API.

## Setup

1. Open a terminal in `frontend`.
2. Run `npm install`.
3. Run `npm start`.

## Notes

- API base URL is configured in `src/environments/environment.ts`.
- Login and registration are available at `/login` and `/register`.
- Feature pages are available at `/dashboard`, `/patients`, `/doctors`, `/appointments`, `/billing`, `/emergency`, `/lab-reports`, and `/pharmacy`.
- The app uses localStorage to store JWT tokens.
